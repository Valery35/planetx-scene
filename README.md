# planetx-scene

Формат сцены PlanetX и проверочные сцены. Общий контракт трёх
продуктов линейки:

- PlanetX - модуль QGIS, github.com/Valery35/planetx;
- PlanetX Lite - своя программа и страница;
- RustPlanetX - расширение RustGIS.

## Состав

- `SCENE.md` - описание формата `.planetx`: поля `scene.json`,
  профиль KML меток, туры, время, модели, номер версии формата.
- `scenes/` - проверочные сцены. Источник - демо модуля
  (`planetx/demo`).
- `expected/` - ожидаемый разбор каждой сцены. Тесты модуля и Lite
  сравнивают свой разбор с ним.
- `tools/expected.py` - снимает `expected/` ядром модуля, эталон
  формата - модуль. Запуск из корня хранилища:

  ```
  python -I tools/expected.py <папка planetx/core модуля>
  ```

## Кто проверяет

- PlanetX Lite - тест `crates/scene/tests/contract.rs`, CI берёт это
  хранилище и задаёт `PLANETX_SCENE`.
- Модуль PlanetX - тест `planetx/tests/test_scene_contract.py`,
  папка - `PLANETX_SCENE` или `planetx-scene` рядом с рабочей копией.

## Правила

- Поле или элемент появляется в формате только через `SCENE.md`.
  Правка формата идёт сюда, потом в модуль и в Lite.
- Несовместимое изменение поднимает номер формата.
- Новая проверочная сцена получает ожидаемый разбор.

Лицензию хранилища выбирает автор.
